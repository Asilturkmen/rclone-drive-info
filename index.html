Rclone-Drive

A personal Google Drive configuration for the open-source Rclone software. It lets one person access and manage their own Google Drive files from Windows and macOS computers.

Read the Privacy Policy

What it is

Rclone is a command-line program for managing files on cloud storage. To connect Rclone to Google Drive, a Google OAuth client is needed. Rclone-Drive is the name of a Google Cloud project, and its OAuth 2.0 client, that I created for my own Rclone installations instead of using Rclone's shared default client.

It is a single-user, personal setup. It is not a commercial service, it is not offered to the public, and it is not a separate cloud storage application.

What it is used for

On my own Windows and macOS computers, Rclone uses this OAuth client to work with files in my Google Drive, for example to:

  • list, download, and upload files and folders;
  • copy and synchronise files between a computer and Google Drive;
  • rename, move, and delete files in Google Drive;
  • mount Google Drive as a local drive or folder;
  • export Google Docs, Sheets, and Slides files to standard formats when downloading.

How authorization works

Access to Google Drive is authorized with Google OAuth 2.0. When a Rclone remote is set up, Rclone opens Google's own sign-in and consent page in the browser. After consent, Google returns tokens to Rclone running on the same computer, and Rclone stores them in its local configuration file. No password is given to Rclone, and nothing passes through this website.

The OAuth client requests Google Drive and Google Docs access so that Rclone can read, create, modify, and delete Drive files. The Privacy Policy describes the requested permissions and how data is handled.

This website does not sign you in or touch any Drive files. It is a static informational page. It has no login, does not perform OAuth authentication, does not call Google APIs, and does not receive, store, or process Google Drive data. All of that happens inside Rclone on my own computers, which talks directly to Google.

About Rclone

Rclone is an independent open-source project (source code on GitHub). Rclone-Drive is only a personal configuration of it. This project is not developed, endorsed, or maintained by the Rclone developers, and it is not developed, endorsed, or maintained by Google. Its Google Drive setup follows Rclone's documentation on making your own client ID.

Revoking access

Access granted to Rclone-Drive can be removed at any time on the Third-party apps & services page of the Google Account. See the Privacy Policy for details.
